# Character Ledger

A D&D 2024 character builder that runs in the browser: <https://cameronlinton03.github.io/dnd-builder/>

On an iPhone, open the link in Safari, tap Share, then **Add to Home Screen**. It opens full-screen like an app and works offline after the first visit.

Characters are saved only in your own browser. Use **Save as a file** to back one up or send it to your DM.

Rules text is from the System Reference Document 5.2 by Wizards of the Coast LLC, licensed CC BY 4.0.
